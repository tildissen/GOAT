# Beslut

Här samlas alla beslut som Tilda tar om G.O.A.T. – vad spelet ska vara, hur det ska fungera och hur det byggs. Varje beslut skrivs in i [beslutslogg.md](beslutslogg.md) så fort det är taget.

## Så läser du loggen

Varje beslut har ett nummer (B1, B2 …), ett datum och följande delar:

- **Beslut** – vad som bestämdes
- **Alternativ** – vad som också övervägdes (om det fanns val)
- **Varför** – motivering, när det finns en
- **Var i koden** – var beslutet syns, så att det går att hitta och ändra

Ändras ett beslut senare skrivs ett *nytt* beslut som ersätter det gamla, och det gamla markeras med **Ersatt av Bxx**. Inget stryks, så historiken finns kvar.
